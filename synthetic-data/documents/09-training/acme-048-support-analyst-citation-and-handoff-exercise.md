# Support Analyst Citation and Handoff Exercise

> Synthetic Acme Corporation document. Reference date: September 11, 2026.

## Learning objective
Practice answering a customer or employee question with traceable evidence. Use only the synthetic Acme documents. The exercise tests source selection and careful language, not memorization of an answer script.

## Scenario one: purchasing
A requester asks about a $7,200 annual software purchase today. Locate the current procurement policy and approval matrix. Identify the required reviews, explain why the archived threshold is not current, and include document titles in the handoff. If a conflicting office-hours note appears, describe its authority rather than choosing it because it is newer.

## Scenario two: delivery
A customer asks whether five Harbor attempts means five retries after the initial attempt. Find the connector contract and explain the sequence. Use the incident report only as an example of observed behavior, not a replacement for the contract.

## Scenario three: missing knowledge
A customer asks for the approved European Beacon hosting region. Identify the unresolved proposal and escalate the decision gap to Leo Martin. Do not substitute a likely region. For ambiguous requests such as 'When does the project launch?', ask which project and whether the user needs a historical target or the current forecast.
